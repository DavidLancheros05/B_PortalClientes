Este proyecto nace a partir de un sistema ya existente llamado **Comercial**,
que tiene su propia base de datos y con el cual Cartonera gestiona su
operación interna (por ejemplo, ahí se crean los productos).

Se requiere construir un **Portal de Clientes nuevo** que reutilice esa
misma base de datos, adaptándola, para que el cliente pueda entrar y hacer
una solicitud de vinculación comercial o una solicitud de aumento de cupo,
llenando un formulario.

Con esto, la solicitud pasa a un flujo de gestión interna por parte de
Cartonera para obtener un resultado. Si es favorable, el cliente pasa a
**Siesa** — el ERP final donde queda registrado el cliente ya vinculado y
donde se generan sus pedidos y facturas.

Además, el cliente podrá ver información de sus pedidos, cartera y
facturas, consultada directamente desde Siesa.
